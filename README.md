# Udemy Project

A simple Udemy homepage clone built with HTML and CSS.

---

Features
- Navbar with search, cart, notifications, and profile  
- Categories section (Development, Business, IT & Software, etc.)  
- Sale banner image  
- Recommended & Popular courses grid  
- Topics section with trending skills  
- Footer with useful links  

---

Tech Stack
- HTML5  
- CSS3  
- Google Fonts (Gabarito)
